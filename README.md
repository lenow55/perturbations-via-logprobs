# пертурбации по словам

## Описание

код для поиска слов в контексте, которые важны
для генерации текста из ЛЛМ

## настройка окружения

установка для разработки:

```
poetry install --with dev
```

нужно устанавливать пакет

```
pip install -e .
```

## распаковка данных

```bash
unzip MuSeRC.zip -x __MACOSX/*
```
